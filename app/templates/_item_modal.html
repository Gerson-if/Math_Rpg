{# Shared "ver detalhes do item" modal — used by character/espolios.html, market/index.html and character/equipamentos.html. Each page keeps rendering its own per-item detail block server-side exactly as before (name, rarity, passive stat, and whichever forms that page needs — equipar/vender/descartar/anunciar, or comprar, or desequipar) but as a permanently-hidden node instead of a `:target`-toggled one; clicking a thumbnail/card no longer follows a URL fragment into a fixed side panel — it clones that hidden block into this one shared modal and shows it centered over the page instead. Content and every form inside it are the same server-rendered HTML as before (CSRF token included), so submitting them works exactly like it always did — only the *display mechanism* changed. A trigger element just needs: `data-item-modal-target="some-id"` where `some-id` is the id of the hidden source block to clone. #}
